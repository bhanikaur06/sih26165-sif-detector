# SIH26165 — SIF Precursor Detection Engine

Prototype for Smart India Hackathon problem statement SIH26165 (Oil India
Limited): an AI/NLP engine that classifies unsafe-act/unsafe-condition and
near-miss reports as Serious Injury & Fatality (SIF) precursors, tags them to
IOGP Life-Saving Rules, and surfaces precursor density on a dashboard.

## Team

- Data track — `/data`
- Backend track — `/backend`
- Frontend track — `/frontend`

Each folder has its own `CLAUDE.md`. The shared contract (schema, API shape,
code style) lives in the root `CLAUDE.md` — read that first.

## Getting started

```bash
git clone <repo-url>
cd sih26165-sif-detector
```

Each person works mainly inside their own folder. Pull before every session,
and if you touch the root `CLAUDE.md` contract, tell the other two before
pushing.
